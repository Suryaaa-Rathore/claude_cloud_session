# Raw

Unedited source footage. **Create one subfolder per video you want edited**, e.g.:

```
raw/
  2026-11-02_product-launch/
    clip-01.mp4
    clip-02.mp4
    notes.md   <- optional: what this video is about, key moments, target platform
```

`_example-video/` shows the structure — copy or rename it for each new video. Never edit or overwrite files here; keep originals intact.
