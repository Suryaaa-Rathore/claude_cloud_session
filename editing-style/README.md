# Editing Style

Your editing rules, written down so every edit is consistent. Examples of what to document:

- Pacing (cut frequency, removing pauses/filler words)
- Captions (font, size, color, position, word-by-word or full lines)
- Transitions, zooms, and B-roll usage
- Music and sound effects (volume levels, style)
- Color grade / LUTs
- Aspect ratios and length per platform (YouTube, Shorts, Reels, TikTok)

Start with a `style-guide.md` file in this folder.
