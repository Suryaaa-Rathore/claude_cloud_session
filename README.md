# AI Video Editing Studio

| Folder | What goes in it |
|---|---|
| `references/` | Videos by others whose style you like |
| `approved/` | Your finished, approved edits — the benchmark for future work |
| `editing-style/` | Written rules for how your videos should be edited |
| `brand-kit/` | Logos, fonts, colors, intros/outros, music |
| `raw/` | Unedited footage — one subfolder per video to edit |
| `exports/` | Rendered outputs from the editing process |

**Workflow:** drop footage into `raw/<video-name>/` → edit using `editing-style/`, `brand-kit/` and `references/` → render to `exports/` → move the keepers into `approved/`.
